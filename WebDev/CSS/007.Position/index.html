CSS Position — The Simple Complete Guide

Every position value explained with clear examples. No JavaScript, just pure CSS.

1. Static (default)

The element stays in the normal document flow. top, left, right, bottom and z-index have no effect.

position: static;

I'm a static box

I sit exactly where I'm written. Offsets are ignored.

2. Relative

The element moves relative to its original position. It keeps its original space – other elements don't move.

position: relative; top: 20px; left: 30px;

Relative Box

I shifted down 20px and right 30px from where I would normally be.

The space I originally occupied is still there (dashed outline).

3. Absolute

Removed from the flow. Positioned relative to the nearest positioned ancestor (an element with position: relative, absolute, fixed, or sticky). If none exists, it uses the <html> element.

Parent: position: relative; (the positioning context)
Parent (relative)

Absolute Box

top: 20px; left: 30px; – inside the dashed parent.

4. Z‑Index (stacking order)

Controls which element appears on top when they overlap. Only works on positioned elements (not static). Higher number = on top.

Box 1 (z‑index: 1) & Box 2 (z‑index: 2)

Box 1

z-index: 1

Box 2

z-index: 2

5. Sticky

A hybrid – behaves like relative until the scroll reaches a threshold (e.g., top: 0), then it sticks like fixed within its parent.

Sticky header – scroll inside the box below

Start scrolling inside this container…

The green bar will stick at the top when you scroll past it.

Keep scrolling – it stays visible while the rest moves.

It un-sticks when its parent scrolls out of view.

Perfect for section headers or navigation.

Still scrolling? You'll see the sticky effect clearly.

6. Fixed

Completely removed from the document flow. Positioned relative to the browser viewport. It stays in the same place even when the page scrolls.

Look at the bottom‑right corner of the screen. The blue circle is fixed there and will never move.
