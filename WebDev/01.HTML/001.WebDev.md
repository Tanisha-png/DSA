# HTML Beginner Notes

## Why `index.html`?

`index.html` is the default page most web servers load automatically
when someone visits a website folder.

Example:

``` text
website/
├── index.html
├── about.html
```

Visiting `https://example.com/` opens `index.html`.

``` html

```

## Elements

## Attributes

