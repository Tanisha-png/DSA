# 2D Dynamic Programming

Open **2D_DP_Handbook.html** in a browser. It is a single self-contained page (it only needs the internet for fonts).

| Path | What it is |
| --- | --- |
| `2D_DP_Handbook.html` | The built website. Do not edit this file directly. |
| `2D_DP_Universe.md` | The study sheet in Markdown. **The code shown on the website is taken from this file.** |
| `src/template.html` | Page layout, styles and the "Start here" / quiz / cheat-sheet sections |
| `src/content.js` | Problem text, DP cards, "try first" questions, quiz and study plan |
| `src/viz.js` | Step-through tables for all 22 problems |
| `src/diagrams.js` | SVG diagrams |
| `src/main.js` | Page behaviour (steppers, code tabs, progress, quiz, navigation) |
| `scripts/build.js` | Builds the HTML from `src/` and the `.md` |
| `scripts/verify.js` | Runs every code block in the `.md` against LeetCode examples |
| `scripts/checkviz.js` | Checks every step-through table against those solutions on random inputs |
| `scripts/tables.js` | Prints the dry-run tables used in the `.md` |

After changing anything:

```bash
cd ~/Desktop/DynamicProgramming/2D
node scripts/verify.js && node scripts/checkviz.js && node scripts/build.js
```
