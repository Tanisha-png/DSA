# DSA Notes

Open `site/index.html` in a browser. Home → Dynamic Programming → 1D DP / 2D DP.

| Path | What it is |
| --- | --- |
| `site/` | Built pages. Don't edit by hand. |
| `2D_DP_Notes.md` | Markdown copy of the 2D DP page, generated by the build. |
| `src/content.js` | Topics, problem text, DP cards, quiz, plan |
| `src/solutions.js` | JavaScript solutions (lines ending `// memo` are the memo lines) |
| `src/viz.js` | Step-through tables |
| `src/diagrams.js` | SVG diagrams |
| `src/main.js` | 2D page behaviour |
| `src/common.js` | Theme toggle, used on every page |
| `src/style.css` | Styles for every page |
| `src/pages/dp-2d.html` | 2D page layout and the Basics / quiz / summary sections |
| `scripts/verify.js` | Runs every solution against LeetCode examples |
| `scripts/checkviz.js` | Checks every stepper against the solutions on random inputs |
| `scripts/build.js` | Builds `site/` and `2D_DP_Notes.md` |

After any change:

```bash
node scripts/verify.js && node scripts/checkviz.js && node scripts/build.js
```
