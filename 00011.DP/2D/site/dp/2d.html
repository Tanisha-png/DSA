    Basics

    How every solution is built

    • DP = a series of choices, the same sub-question shows up on different routes, and the best answer is built from best sub-answers.
    • 2D = you need two numbers to say where you are.
    • Test: what is the least I need to know about where I am to finish the problem? If that is two numbers, it is 2D.

    Four versions of one solution

    1RecursionCorrect, slow. Get the logic right.
    2MemoSame code + a cache. Two extra lines.
    3TableLoops instead of recursion. No stack limit.
    4One rowKeep only the rows still needed.
    • In the code boxes, memo lines have a yellow bar.
    • The Recursion tab is the same code with those lines removed.

    Why the memo matters

    Plain recursion on a 3 × 3 grid. The orange part is computed twice: two routes lead to (1,1).

    Fill direction

    • Follow the question. If it walks start → end (robot, strings, items, days), fill start → end. dp = answer for what is done so far.
    • Go in reverse only when it helps:
      • the start depends on what lies ahead (A6 Dungeon), or
      • reverse puts the answer in one cell (A4 Triangle).
    • Intervals (D): short ranges first, then longer.
    • Loop rule: reads i − 1 → loop i up. Reads i + 1 → loop i down.
    • Every DP card has a Fill order row, and the stepper starts there.

    Padding is the base case

    • Add one extra row and column holding the base value.
    • The loops then need no "am I outside?" checks.
    • In the steppers, padding cells are dashed and filled before step 1.

    Explaining it in an interview

    1. dp(i, j) means …
    2. To get here I could …, so dp(i, j) = …
    3. It stops when …
    4. The answer is …
    5. States × work per state = time.
    6. Top-down first, then a table, then keep one or two rows.
