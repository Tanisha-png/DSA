# 1. What is a Function?

## Definition

A function is a reusable block of code that performs a specific task.

## Why Do We Need Functions?

Imagine you need to print the same message multiple times.

Without functions:

```javascript
console.log("Hello Arvinder");
console.log("Hello Arvinder");
console.log("Hello Arvinder");
console.log("Hello Arvinder");
```

The same code is repeated again and again.

With functions:

```javascript
function greet() {
    console.log("Hello Arvinder");
}

greet();
greet();
greet();
greet();
```

## Benefits of Functions

1. Reusability
2. Less code duplication
3. Easier maintenance
4. Better readability

# 2. Function Call

Creating a function does not execute it.

A function runs only when it is called.

```javascript
function greet() {
    console.log("Hello");
}

greet();
```

Output:

```text
Hello
```

# 3. Parameter vs Argument

## Parameter

A variable written inside the function definition.

## Argument

The actual value passed during the function call.

```javascript
function greet(name) {
    console.log("Hello", name);
}

greet("Arvinder");
```

Explanation:

```javascript
function greet(name)
```

`name` is the Parameter.

```javascript
greet("Arvinder")
```

`"Arvinder"` is the Argument.

## How to Remember

```text
Parameter = Placeholder

Argument = Actual Value
```

# 4. Return Keyword

## Definition

Return sends a value back from a function.

As soon as JavaScript encounters a return statement, the function immediately stops executing.

```javascript
function getAge() {
    return 25;
}

let age = getAge();

console.log(age);
```

Output:

```text
25
```

## Important

```javascript
function demo() {
    return "Hello";

    console.log("This will never execute");
}
```

Any code written after `return` inside the same block will not execute.

# 5. Four Types of Functions

There are four common combinations of Parameters and Return Values.

| Parameters | Return Value |
| ---------- | ------------ |
| No         | No           |
| Yes        | No           |
| No         | Yes          |
| Yes        | Yes          |

---

## Type 1: No Parameter and No Return

### Example

```javascript
function ringBell() {
    console.log("School Started");
}

ringBell();
```

### Characteristics

```text
Input  : No
Output : No
```

---

## Type 2: Parameter and No Return

### Example

```javascript
function serveFood(food) {
    console.log("Serving", food);
}

serveFood("Pizza");
```

### Characteristics

```text
Input  : Yes
Output : No
```

---

## Type 3: No Parameter and Return

### Example

```javascript
function getTemperature() {
    return 30;
}

console.log(getTemperature());
```

### Characteristics

```text
Input  : No
Output : Yes
```

---

## Type 4: Parameter and Return

### Example

```javascript
function add(a, b) {
    return a + b;
}

console.log(add(10, 20));
```

### Characteristics

```text
Input  : Yes
Output : Yes
```

# 6. Closures

## Definition

A closure happens when an inner function remembers variables from its outer function even after the outer function has finished execution.

## Example

```javascript
function outer() {
    let money = 100;

    function inner() {
        console.log(money);
    }

    return inner;
}

const locker = outer();

locker();
```

Output:

```text
100
```

## What Happened?

1. `outer()` executes.
2. `money` is created.
3. `inner()` is returned.
4. `outer()` finishes.
5. `inner()` still remembers `money`.

## Key Point

```text
Closure = Remembering outer variables
```

# 7. Higher Order Functions (HOF)

## Definition

A Higher Order Function is a function that:

1. Accepts another function as an argument

OR

2. Returns another function

---

## Example 1: Accepting a Function

```javascript
function sayHello() {
    console.log("Hello");
}

function execute(fn) {
    fn();
}

execute(sayHello);
```

Output:

```text
Hello
```

---

## Example 2: Returning a Function

```javascript
function createMultiplier(number) {
    return function(value) {
        return value * number;
    };
}

const double = createMultiplier(2);

console.log(double(5));
```

Output:

```text
10
```

## Key Point

```text
Higher Order Function = Works with other functions
```

---

# 8. Callback Functions

## Definition

A callback is a function passed into another function to be executed later.

## Example

```javascript
function notify() {
    console.log("Task Completed");
}

function performTask(callback) {
    console.log("Working...");
    callback();
}

performTask(notify);
```

Output:

```text
Working...
Task Completed
```

## Key Point

```text
Callback = Function passed as an argument
```

---

# 9. Relationship Between Closure, HOF and Callback

Many beginners confuse these concepts.

## Closure

```text
Remembers outer variables
```

## Higher Order Function

```text
Accepts or returns functions
```

## Callback

```text
Function passed into another function
```

### Important

```text
Every Callback is a Function.

A Callback is usually passed to a Higher Order Function.

A Closure is a completely different concept.
```

# 10. Common Array Higher Order Functions

Assume:

```javascript
const numbers = [1, 2, 3, 4, 5];
```

---

## forEach()

### Purpose

Perform an action for every element.

```javascript
numbers.forEach(function(num) {
    console.log(num);
});
```

Output:

```text
1
2
3
4
5
```

---

## map()

### Purpose

Transform each element and return a new array.

```javascript
const doubled = numbers.map(function(num) {
    return num * 2;
});

console.log(doubled);
```

Output:

```javascript
[2, 4, 6, 8, 10]
```

---

## filter()

### Purpose

Keep elements that satisfy a condition.

```javascript
const evenNumbers = numbers.filter(function(num) {
    return num % 2 === 0;
});

console.log(evenNumbers);
```

Output:

```javascript
[2, 4]
```

---

## reduce()

### Purpose

Combine all elements into a single value.

```javascript
const total = numbers.reduce(function(sum, num) {
    return sum + num;
}, 0);

console.log(total);
```

Output:

```javascript
15
```

---

# Arrow Function Versions

## map()

```javascript
const doubled = numbers.map(num => num * 2);
```

## filter()

```javascript
const evens = numbers.filter(num => num % 2 === 0);
```

## reduce()

