# Data Structures & Algorithms Assessment

## Overview

The assessment consists of two parts, each in its own directory. Follow the directions in this README for instructions on each part, then make a PR from your fork into the upstream in order to submit the assessment.

## Getting Started

- [ ] Fork and clone this repository. If you need a refresher, just follow the instructions found [here](https://github.com/CodesmithLLC/dev-environment-setup/blob/main/fork-clone.md)!

## PART 1

Complete the three functions in `part-1/main.ts`.

- [ ] `verifyNums()`
- [ ] `flattenedValues()`
- [ ] `splitSum()`

## PART 2

- [ ] In `part-2/main.ts`, implement a `BinarySearchTree` class that uses BinarySearchTree nodes to the left and right to store a collection of values.

NOTE: Remember that the BinarySearchTree sorts elements added by greater than and less than. Items greater than the current node's value are placed on the right and items less than the current node's value are placed on the left.

- [ ] Implement an `add` method that can take in **any number of arguments**. For all passed-in values, add a new node to the correct place in the tree.

- [ ] Implement a `depth` method, which will count the levels of the Binary Search Tree and return its depth. Note that the first level of the tree (i.e. the root) should start at 1.
